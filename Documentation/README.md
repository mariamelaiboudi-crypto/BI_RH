# Exmple : A Visualized Analysis on Student Performance by Using Cloud Business Intelligence

## Project Overview
This project focuses on analyzing and visualizing student academic performance, particularly during the COVID-19 pandemic. It addresses the trend of deteriorating academic performance by implementing Business Intelligence (BI) tools to gain deeper insights into Course Learning Outcomes (CLO).

The study compares various BI tools and utilizes **Microsoft Power BI** alongside **Python** to develop interactive dashboards that highlight student weaknesses across different domains (Cognitive, Practical, and Affective).

## Key Features
- **BI Tool Comparison:** Evaluation of Power BI, Tableau, and IBM Cognos Analytics.
- **Hybrid Approach:** Integration of Power BI for rapid dashboarding and Python (Pandas/Matplotlib) for customized, programmatic data analysis.
- **Educational Framework:** Application of **Bloom's Taxonomy** to categorize student performance.
- **In-depth Analysis:** Dashboards covering Midterm, Practical, Assignment, and Final Exam results.
- **Recommendations:** Data-driven suggestions for educational institutions to improve student engagement and foundational knowledge.

## Methodology
1. **Data Collection & Preparation:** Gathering student scores and cleaning data using Excel.
2. **BI Tool Selection:** Comparative analysis of market-leading BI solutions.
3. **System Design:** Creating block diagrams and system architectures for the data pipeline.
4. **Implementation:**
    - **Power BI:** Data transformation (Power Query) and interactive visualization.
    - **Python:** Programmatic analysis using Jupyter Notebooks.
5. **Evaluation:** Discussion of findings based on program of study, gender, and assessment types.

## Tools & Technologies
- **Business Intelligence:** Microsoft Power BI
- **Programming:** Python (3.9+)
- **Libraries:** Pandas, Matplotlib, Numpy, Squarify, Plotly
- **Environment:** Anaconda Navigator, Jupyter Notebook
- **Data Source:** Microsoft Excel (.csv)

## Key Findings
- Computer Science (CS) students generally outperformed Information Systems (IA) and Business Information Systems (IB) students in coding-related tasks.
- Students performed better in the **Psychomotor domain** (practical tasks) compared to the **Cognitive domain** (theoretical tests) in some assessment categories.
- Female students showed slightly higher average scores in cognitive-based assessments (Midterm), while male students excelled in practical-based assessments.

## Future Work
- Implementation of more complex BI tools like Tableau for large-scale datasets.
- Integration of **Microsoft SQL Server** for robust data management.
- Adoption of **Self-Service BI** and **Agile BI Development** workflows.
